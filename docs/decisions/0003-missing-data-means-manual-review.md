# 0003. Нет данных — ручная проверка

**Контекст.** У молодой компании нет кредитной истории, у ИП часто нет отчётности. Если считать «нет просрочек» плюсом, модель награждает за незнание; если отказывать, банк теряет хороших клиентов.

**Решение.** Критерий без данных получает 0 баллов с пометкой «Нет данных», а заявка с хотя бы одним пробелом никогда не решается автоматически — ни одобрением, ни отказом. Сотрудник видит перечень пробелов и то, что система сделала бы без них. Отказ без данных возможен только по условиям допуска (нет выручки, компании нет в реестре).

**Отвергли.** Подстановку средних значений: пропуск обычно несёт информацию, а статистики для честной подстановки у прототипа нет.

**Цена.** Больше ручной работы на молодых компаниях. Развитие: отдельная упрощённая карта на денежном потоке из выписки. Подробно: [scoring.md](../scoring.md#если-данных-нет).
