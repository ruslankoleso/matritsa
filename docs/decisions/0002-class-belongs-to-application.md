# 0002. Класс риска относится к заявке

**Контекст.** Один и тот же заёмщик может потянуть 2 млн ₽ и не потянуть 20 млн ₽. Если класс считать только по заёмщику, большая заявка получит тот же класс и ту же ставку.

**Решение.** DSCR в баллах считается с платежом по новому кредиту (по базовой ставке продукта, чтобы расчёт не замкнулся). Слишком большая заявка теряет баллы и уходит на встречные условия, а меньшая сумма оценивается отдельно, как самостоятельная ссуда со своим классом. Это согласуется с 590-П: категорию качества присваивают ссуде.

**Отвергли.** Класс заёмщика плюс отдельный лимит суммы: проще, но ставка тогда не отражает риск конкретной ссуды.

**Цена.** Класс в разных заявках одного клиента разный; это приходится объяснять (подсказка в карточке аналитика). Подробно: [scoring.md](../scoring.md).
