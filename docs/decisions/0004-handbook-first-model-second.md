# 0004. Справочник первым, модель вторым; T-lite-it-2.1

**Контекст.** Ответ чата банка воспринимается как обещание. На 12 вопросах по теме обе проверенные открытые модели придумывали сроки, условия и телефон (4 и 3 выдумки соответственно).

**Решение.** Точные вопросы (документы, ставки, сроки, статус, оценка) отвечает справочник из каталога и заявок клиента. Модель подбирает продукт по свободной фразе и поясняет предыдущий ответ. Её ответ и пересказ оценки проверяются кодом: цифры только из фактов, без обещаний и выдуманных сроков; при сомнении показывается справочник. По умолчанию — T-lite-it-2.1 (Apache 2.0): точнее по-русски и единственная верно сопоставила сумму и срок с продуктами. ИИ выключен по умолчанию, всё работает без него.

**Отвергли.** Модель на всё (выдумки) и только справочник (не понимает «800 тысяч на год»). Qwen3.5 4B ошибалась в подборе продукта.

**Цена.** Модель весит около 5 ГБ и отвечает 2–12 секунд на процессоре. Проверка цифр не ловит смысловых ошибок, поэтому ответ ИИ помечен. Подробно: [ai-chat.md](../ai-chat.md).
