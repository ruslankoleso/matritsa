# 0006. EAD — средний остаток долга

**Контекст.** Ожидаемые потери EL = PD × LGD × EAD. Сумма под риском в первой версии равнялась всей запрошенной сумме, хотя кредит гасится равными платежами и дефолт может случиться в любом месяце.

**Решение.** EAD — средний остаток долга по аннуитетному графику за срок (`scoring.AverageExposure`): для кредита на год около 54 % суммы, для длинных сроков ближе к половине.

**Отвергли.** Всю сумму (завышает потери почти вдвое) и остаток на момент дефолта по кривой выживаемости (точнее, но без данных о моменте дефолта это та же оценка с лишней сложностью).

**Цена.** Ожидаемые потери в карточке стали меньше; надбавка к ставке не изменилась, она от EAD не зависит. Подробно: [scoring.md](../scoring.md#шаг-3-ожидаемые-потери-el).
